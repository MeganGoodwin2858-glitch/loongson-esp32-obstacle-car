# BLE 360° 手机遥控（UART/HC-SR04整合版）

本版已经实现先锋派UART接收、HC-SR04测距和主机避障状态机。完整接线、使用、编译及验证边界请先看 `README_UART_HCSR04.md`，协议见 `docs/uart-hcsr04-protocol.md`。

## 手机界面

保留 `phone/index.html` 与 `phone/controller.js`。通过HTTPS或浏览器所在设备的localhost提供页面，Android可使用支持Web Bluetooth的Chrome/Edge。iOS Safari不支持；真实手机兼容性尚未验证。

点击连接，选择 `Xiaozhi-Car-360`。手机手动模式先点使能，再按住圆形摇杆；松手停车并取消使能，下一次需重新使能。默认速度40%，支持0..100%，12%径向死区。两轮差速可连续转弯和原地旋转，不能横向平移。

急停锁存；解除后保持停车，需再次使能。手动/自动300ms没有新DRIVE即停车，BLE断连停车。软件时间阈值不是实测机械停车时间或距离。

## 模式

- 手机手动：当前BLE控制者驱动车轮。HC-SR04自动联锁不强制干预人工模式，便于人工接管。
- 龙芯自动：本版默认编译UART1和HC-SR04。手机选择该模式后保持连接，由先锋派 `loongson/avoidance_uart.py` 完成三次新测距、ARM确认及持续控制；UART程序默认monitor，运动须明确双开关。手机不要在此模式点击“使能本次操控”，由先锋派握手使能。
- 原功能：手机选择并使能后，原网页/MCP/语音情绪可驱动车轮，其他语音、显示、音频和网络功能保留。原功能动作队列有限，整段舞蹈可被停车完整取消；断连也停车。

模式切换先停车并轮换会话，旧UART残留不会打断新的手动接管。紧急停止仍可跨模式锁定。Blufi与遥控独立拥有蓝牙栈，Kconfig禁止同时启用；使用原热点配网。

## 代码和测试

电机输出统一到 `main/car_control/`，引脚仍为12/13/14/21、20kHz/10bit；PWM失败不降级成全速GPIO。手动/自动/原功能独占，旧延时停车与延时逐段提交舞蹈在选中配置下停用。

原 `loongson/car_uart.py` 只作为兼容协议工具保留，不是本版避障入口。不要使用它替代 `avoidance_uart.py` 的采样时效与握手流程。

既有BLE和网页回归、新测距与联锁、主机状态机和双板字节流测试均在交付记录中列出。真实GPIO、供电、Echo降压、PWM、无线/音频共存、LinuxUART和避障效果都需按新指南实物验收；本次没有烧录。
