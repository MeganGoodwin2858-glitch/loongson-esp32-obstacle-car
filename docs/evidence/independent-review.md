# 本次独立复查记录

范围：car-v2的RMT采集、距离有效性、本地联锁、UART解析、先锋派状态机及会话生命周期。复查为只读，没有设备运行。

已发现并修复：
1. RMT输入滤波使用分组80MHz时钟，原10us过滤需要800计数，超过8bit限制；改1us，并加入合同断言和先失败后通过的回归。
2. 自动模式旧UART半帧超时可能误停新的手动接管；改为UartReceiver绑定首字节所在的auto_session，旧片段不能影响新模式/会话。
3. 实际IDF中RMT disable不等待另一核已进入的ISR；将采集任务固定到初始化/中断分配所在核，并限制app_main固定CPU0/CPU1，避免旧回调跨轮复用。
4. 100Hz tick相位会让简单周期等待短于80ms；改为esp_timer绝对单调期限并在实际TRIG上升沿后设置最早下一次触发，睡眠向上取整并再次检查。
5. Python新增对CRC正确但结果码/距离/flags/sample_seq语义不一致的拒绝检查。

最终固定CPU0配置下，复查未发现其他需阻断交付的具体问题。实际RMT波形/噪声、Linux termios/UART与实车避障仍待上板验收。测试与完整目标构建证据由主代理独立执行并保留。
