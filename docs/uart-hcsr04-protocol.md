# 先锋派 UART 与 HC-SR04 遥测协议

UART物理层：3.3V TTL，共地、TX/RX交叉，115200、8数据位、无校验、1停止位，无硬件流控。先锋派使用UART2 `/dev/ttyS2`，ESP32使用UART1。所有帧20字节，多字节整数小端，CRC16/CCITT-FALSE覆盖前18字节（poly=0x1021/init=0xffff/xorout=0；标准向量`123456789`→0x29b1）。接收方必须按长度和CRC组帧，不能按一次read等于一帧来处理。

## 先锋派→ESP32：命令0xa5

沿用BLE v1命令，详见 `ble360-protocol.md`：头0xa5/版本1、操作码、速度、u32递增序号、i16 x/y、u32会话、模式参数、保留0、CRC。

DRIVE=1、STOP=2、ARM=3、ESTOP=4、CLEAR=5、MODE=6。UART只在已选择自动模式时接受ARM/DRIVE/STOP，ESTOP可跨模式锁停；MODE和CLEAR只能由BLE操作。非DRIVE的x/y必须为0。自动驾驶使用y>=0；本避障程序不发倒车指令。序号从1起严格递增，到0xffffffff后必须重新握手，禁止静默回绕。

会话由ESP32状态帧的auto_session给出，不能自行假定。停车、错误、超时、模式变化会更换会话；恢复需人工重新选择模式/重新运行客户端。UART旧会话在手机已切到手动后不会打断新的手动控制。

## ESP32→先锋派：状态0x5a

| 偏移 | 字段 |
|---|---|
| 0 | 0x5a |
| 1 | 版本1 |
| 2 | 模式：0手动、1龙芯自动、2原功能 |
| 3 | flags：bit0已使能、bit1急停、bit2BLE连接、bit3UART已配置 |
| 4..7 | BLE session u32 |
| 8..11 | auto_session u32 |
| 12..13 | 左轮有符号百分比 i16 |
| 14..15 | 右轮有符号百分比 i16 |
| 16..17 | 保留0 |
| 18..19 | CRC u16 |

左右输出包含自动模式本地联锁后的软件指令值，不是编码器测速或实际电机转速。

## ESP32→先锋派：测距0x5b（新增）

| 偏移 | 字段 |
|---|---|
| 0 | 0x5b |
| 1 | 版本1 |
| 2 | 结果：0有效、1无Echo/超时、2超范围、3异常多脉冲/驱动错误、4传感器关闭、5采样过期 |
| 3 | flags：bit0测距已配置、bit1前进受限、bit2全部自动运动受限；其余0 |
| 4..7 | auto_session u32，与状态帧绑定 |
| 8..11 | sample_seq u32；每次新采样尝试递增，0表示尚无采样 |
| 12..13 | distance_mm u16；无效固定0xffff，不表示65535mm无障碍 |
| 14..15 | age_ms u16，距采样触发的年龄，饱和65535；非两板时钟比较 |
| 16..17 | echo_us u16，原始Echo高电平时间，饱和65535；距离可能经保守滤波 |
| 18..19 | CRC u16 |

有效样本20..4000mm、年龄<=180ms；有效帧flags必须与距离一致：enabled | (distance<=300?2:0) | (distance<=120?4:0)。原地转向在120..300mm区间可被允许，自动前进被禁止。无效/过期帧不得延续上一次“道路畅通”。

UART每50ms尝试依次发送状态与测距各一帧；传感器新采样不短于80ms，因此可能收到相同sample_seq。重复帧不能计入3次准备/清路，也不能延长采样寿命；主机用接收时刻减age估算采样时刻，重复时只可缩短其有效期。序号倒退、语义不一致、CRC/组帧错误、缓冲溢出均停止当前自动会话，不自动恢复。不同会话的遥测丢弃。

## 握手和时限

1. 手机连接后选择Auto，ESP32停车且auto_session轮换。先锋派端看到mode=1、BLE与UART标志、未急停、未使能后绑定会话；已经使能的会话拒绝接管。
2. 收到同会话3次新的有效样本后，主机发ARM并等更新后的已使能状态。没有ACK不发DRIVE，ACK最长等150ms。
3. 进入控制后每50ms发DRIVE；刹车/稳定阶段发x=y=0的DRIVE维持会话，STOP用于终止并取消使能。
4. 主机150ms没有新状态、180ms测距过期或任一故障立即终止。ESP32独立执行180ms传感器联锁和300msDRIVE watchdog，不依赖主机正常退出。
5. 主机发现模式/会话已经改变时退出，不对新模式发送旧STOP；本地故障且原会话仍有效时尽力STOP。手机急停始终锁存，解除不恢复运动。

本协议无身份认证和加密；CRC用于数据完整性，session/seq用于生命周期与旧指令隔离。BLE手机和UART均未替代物理电源急停。
