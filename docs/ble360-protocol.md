# BLE / 龙芯 UART v1 协议

所有多字节整数小端。每帧固定 20 字节，适配默认 ATT MTU=23；UART=115200、8N1。CRC16/CCITT-FALSE（poly=0x1021，init=0xffff，xorout=0；`123456789` → 0x29b1），覆盖字节 0..17。

GATT service `7bc03600-186c-4a8d-4245-363600000001`；命令 Write With Response `...0002`；状态 Read `...0003`。状态由客户端串行读取，不使用 Notify。完整 UUID 的前 32 位至倒数 4 位相同。

## 命令

| 字节 | 类型 | 意义 |
|---|---|---|
| 0 | u8 | 0xa5 |
| 1 | u8 | 版本 1 |
| 2 | u8 | DRIVE=1 / STOP=2 / ARM=3 / ESTOP=4 / CLEAR=5 / MODE=6 |
| 3 | u8 | 速度上限 0..100 |
| 4..7 | u32 | 序号，1 起严格递增，不允许回绕；重新连接/重新选择自动模式后重新握手 |
| 8..9 | i16 | x：-1000..1000 |
| 10..11 | i16 | y：-1000..1000 |
| 12..15 | u32 | BLE 使用 BLE session；UART 使用 auto session |
| 16 | u8 | MODE 参数：0手动 / 1自动 / 2原功能；其他操作必须为 0 |
| 17 | u8 | 保留，必须 0 |
| 18..19 | u16 | CRC |

除 DRIVE 外 x/y 必须为 0。读状态取得当前会话后发 ARM，再发 DRIVE。序号不因状态轮询或普通停车自动重置；客户端始终递增。UART 序号只在手机成功选择新模式时复位。STOP、模式切换、断连、急停、解除、超时、无效命令会轮换会话，因此停车前的缓存 DRIVE 无法在恢复后复活。

ESTOP 仍必须通过长度、CRC、字段检查，但不会被过期序号/会话过滤。STOP、模式切换前应清空客户端待发送运动；手机实现最多一项正在发送及一份最新运动，过期 150ms 的待发运动直接丢弃。急停优先于所有待发按钮操作。

UART 只在手机已经选择自动模式时接受 ARM/DRIVE/STOP；CLEAR 和 MODE 只能由 BLE 发起。有效 ESTOP 可从任一来源锁停。BLE 在自动模式发 DRIVE 会拒绝并停车。原网页/MCP 运动只在原功能模式且使能后接受。不同会话的UART残留半帧和完整旧帧不会打断新手动操控。

## 状态

| 字节 | 意义 |
|---|---|
| 0 / 1 | 0x5a / 1 |
| 2 | 模式 0/1/2 |
| 3 | bit0=已使能，bit1=急停，bit2=BLE 已连接，bit3=UART 可用 |
| 4..7 | BLE session |
| 8..11 | auto session |
| 12..13 | 左轮有符号百分比（i16） |
| 14..15 | 右轮有符号百分比（i16） |
| 16..17 | 保留 0 |
| 18..19 | CRC16 |

UART 开启时，每 50ms 尝试发送状态与 HC-SR04 测距各一帧；主机须按头和 CRC 重同步，新增测距格式见 `uart-hcsr04-protocol.md`。同一自动会话的UART组帧超时100ms或损坏会停车；旧会话残留不打断新的手动操控。连续噪声不能延长DRIVE的300ms有效期。GATT参数错误返回ATT错误并停车，手机关闭连接，需要重新使能。

## 混控

`r=hypot(x,y)`；`r<=120` 输出零。其余令 `m=(min(r,1000)-120)/880`，`v=y/r*m`，`w=x/r*m`，`L=v+w`，`R=v-w`；按 `max(1,abs(L),abs(R))` 共同归一化后乘速度百分比并取最近整数。例如满前进100%=100/100、满右=100/-100、右前对角=100/0、后右对角=0/-100；`x=0,y=560,100%` 为50/50。

硬件输出在统一互斥锁下先令四路低，再设置 LF/LB/RF/RB。检测左右任一轮换向时增加 100us 全低间隔。这里是源码定义的行为，尚未用示波器或实车验证。
