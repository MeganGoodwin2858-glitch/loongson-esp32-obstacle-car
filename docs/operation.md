# 运行与验收说明

## Wi-Fi 手动遥控

手机与 ESP32 连接同一 Wi-Fi，访问启动日志中的设备当前 IP。网页读取真实状态后，点击“使能遥控”，再按住摇杆。默认速度上限 40%，松手、切后台或停车会撤销使能。急停解除后仍需要重新使能。

网页控制入口包含 `/api/remote/status`、`/api/remote/arm`、`/api/remote/command`、`/api/remote/estop` 和 `/api/remote/clear`。控制 POST 需要 `X-Car-Control: 1`。页面和固件使用会话、递增序号、CRC 与 300ms 看门狗。

Wi-Fi 页面采用局域网控制，接口缺少用户身份认证和加密传输。该访问范围需要在团队部署时明确。

## BLE 手动与模式切换

`phone/index.html` 与 `phone/controller.js` 配套使用，通过 HTTPS 或浏览器所在设备的 localhost 提供页面。手机浏览器需要支持 Web Bluetooth，连接设备广播名 `Xiaozhi-Car-360`。

- 手机手动模式先使能，再拖动摇杆。松手停车并撤销使能。
- “龙芯自动”模式由龙芯客户端完成采样准备、ARM 确认和持续 DRIVE，手机保持 BLE 连接。
- “原功能”模式提供已有动作、MCP 和语音情绪控制入口。

“360°”描述摇杆方向输入，两轮差速机构支持连续转弯和原地旋转。手机设备兼容性需要现场验证，历史记录中的华为设备优先使用已存在的 Wi-Fi 手动页面。

## 龙芯避障

预检通过并连续观察有效状态、测距后，再进行现场动作验证。人工切到 Auto，确认接线与场地，运行以下命令。

```sh
python3 avoidance_uart.py --port /dev/ttyS2 --enable-motion --wiring-confirmed
```

程序要求两个运动开关同时提供，默认入口为监视模式。自动控制还要求 BLE 在线、Auto 状态、有效会话、连续三个新测距和新的使能确认。

| 条件 | 软件行为 |
| --- | --- |
| 距离 >450mm | 30% 输出参数前进 |
| 300..450mm | 20% 输出参数前进 |
| 120..300mm | 停车至少 160ms，再以 25% 输出参数原地转向 |
| 转向后连续三个新采样 >450mm | 满足最短转向时间后停车稳定，再进入前进判断 |
| ≤120mm、测距无效或过期、会话/通信故障 | 终止当前自动控制，等待人工处理 |

完整阈值边界以 `loongson/avoidance_uart.py` 和 `main/car_control/` 为准。自动联锁覆盖自动模式，手动模式的障碍判断由操作者承担。输出百分比、时间和距离参数需要通过实车标定形成验收依据。

## 待执行验收

1. 轮子离地，核对左右轮正反向及零输出状态。
2. 短时低速验证松手、急停、断连和命令超时的机械停车。
3. 使用已知距离目标标定 HC-SR04，记录无回波、超范围和噪声行为。
4. 在空旷场地验证单个障碍物的减速、停车、转向与人工接管。
5. 测量负载电压、制动距离、转向角，以及 Wi-Fi/BLE/音频同时运行的稳定性。
6. 定位 OLED 黑屏并记录模块控制器、供电和可见显示证据。
