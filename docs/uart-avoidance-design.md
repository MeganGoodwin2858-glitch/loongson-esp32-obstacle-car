# 先锋派 UART + HC-SR04 实施依据与计划

用户要求读取六个资料包，实现先锋派/ESP32 UART 协议与 HC-SR04 避障，完成可离线进行的烧录前工作，禁止烧录。沿用已交付的小智 ESP32-S3 两轮差速/BLE 项目，另建 car-v2 工作副本。

## 已核实的资料
- 先锋派 G2K03Z1_V1.1 原理图 PDF 第30页：J8 8=UART2 TX、10=UART2 RX，6/9/14等=GND；与引脚复用图一致。
- 用户手册 V2.1 PDF第148页：J8 8/10回环，/dev/ttyS2；第35页J9是另一种扩展板布局，不用于本工程。
- 内核 loongson-2k0300.dtsi：serial2→uart2，寄存器0x16100800，ns16550a；先锋派dts启用uart2。UART0为调试控制台，不占用。
- 数据手册第20页IO_3V3与第35页数字电平资料；原理图J8信号无RS232收发器，采用3.3V TTL交叉接线。
- 编译指南针对Ubuntu22.04/24.04、GCC13.3 ABI2。Windows本机没有已验证可用的Linux/LoongArch工具链。先锋派程序选用系统Python标准库，避免新增二进制驱动和第三方串口库。

## 本次选择
ESP32使用UART1 TX8/RX9连接先锋派UART2 RX/TX，HC-SR04放在ESP32前方，TRIG10/ECHO11（ESP32板上这两脚实物引出尚待核验）。HC-SR04 5V供电，ECHO经1k/2k分压或合适单向电平转换后进入ESP32；不得直连5V ECHO。双板共地，默认不互接电源正极。单个前向传感器不自动倒车。

ESP32用RMT测Echo脉宽，80ms周期、10us触发、25ms接收空闲阈值、60ms软件超时；无回波/异常/过期都标无效，不当作道路畅通。距离按343m/s、20..4000mm验收范围换算；是室温近似而非仪器校准。

UART沿用20字节CRC16命令及状态帧，新增0x5b测距遥测帧：版本、结果码、标志、自动模式会话、采样序号、距离mm、采样年龄ms、Echo us和CRC。BLE协议保持不变。命令8N1/115200，严格序号、会话、300ms命令超时，50ms上报状态/测距。

先锋派状态机：三次有效新采样后准备；前方>450mm巡航30%，300..450mm降速20%，<=300mm先停车160ms再低速原地转向25%；至少转200ms且连续3次>450mm后停车稳定160ms，再前进。转向最长800ms；<=120mm、传感器异常/过期、通信异常、会话切换均终止停车，需要人工重新使能。阈值/占空比/时长是保守初始配置，不是实车标定结果。

ESP32本地自动模式联锁：采样过期180ms或无效取消使能；<=300mm禁止前进，<=120mm禁止全部自动运动。手机急停/断连/模式切换优先。避免先锋派主机卡顿时仍盲目前进。手动模式不强制套用前向避障，保持人工接管能力。
